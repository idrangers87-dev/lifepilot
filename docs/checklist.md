## 2. 시뮬레이터 (Studio Device Simulation)
`lib/config.js`의 `mockKind: 'scenario'`로 서버 없이 먼저, 그다음 실제 서버로.

| 의도 | 말하기 | 기대 상태 변화 | 기대 화면 | 결과 |
| --- | --- | --- | --- | --- |
| 시작 | 이거 어떻게 해 | IDLE → ANALYZING → GUIDING | "보는 중…" → 단계/질문 | |
| 진행 | 다음 | GUIDING → ANALYZING → GUIDING | 다음 동작, 단계 번호 +1 | |
| 재촬영 | 찍어 | → ANALYZING | 같은 단계 재분석 | |
| 반복 | 다시 | 그대로 | 같은 문구 재발화 | |
| 상세 | 자세히 | 그대로 | 상세 설명 표시(읽지 않음) | |
| 긍정 | 응 (질문 화면) | → ANALYZING | 목표 확정, 상태줄에 목표 | |
| 부정 | 아니 (질문 화면) | → ANALYZING | 다른 추정 | |
| 이전 | 이전 | → ANALYZING | 단계 번호 -1 | |
| 종료 | 그만 | → DONE → 3초 후 IDLE | "완료 · N단계 · 시간" | |
| 도움 | 뭐라고 말해야 해 | 그대로 | 명령 목록 | |
| 탭 | 템플 버튼 | 홈: 듣기, 안내: 다음 | | |
| 권한 거부 | 카메라 끄고 시작 | GUIDING/error | "카메라 권한이 필요해" | |
| 네트워크 끊김 | 서버 끄고 다음 | GUIDING/error | "연결이 안 돼", "응"으로 재시도 | |

## 3. 실기 시나리오 5종 × 3회 (2회 이상 성공이면 통과)
| 시나리오 | 성공 기준 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 가전 고장(세탁기·식기세척기 에러) | 코드 읽기 → 안전 단계 → 3단계 이상 → 완료 | | | |
| 기기 설정(공유기 뒷면) | 포트 식별 → 연결 안내, 어두우면 재촬영 | | | |
| 조립(부품 5개 이상) | 부품 구분 → 순서, 헷갈리면 되묻기 | | | |
| 요리(팬 위 상태) | 불·기름 안전 문구 → 뒤집을지/기다릴지 | | | |
| 서류·라벨(약 설명서) | 핵심 2~3줄, 모르면 모른다고, 복용 지시 없음 | | | |
